## 📌 Como Rodar as Soluções
Cada solução está armazenada em arquivos `.cpp`, `.py`, `.js` ou `.sql`. Para rodar, use:

### C++:
```sh
g++ arquivo.cpp -o programa && ./programa
```

### Python:
```sh
python3 arquivo.py
```

### JavaScript:
```sh
node arquivo.js
```

### SQL:
Execute as consultas no banco de dados desejado.
